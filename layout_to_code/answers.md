1. **Инструменты Figma:** Панель Design (справа) — для размеров (W, H), цветов (Fill) и шрифтов. Плагин "CSS Extract" или комбинация Ctrl+Alt+C позволяют скопировать готовый CSS.
2. **Структура переменных:** Переменные группируются по смыслу: сначала основные цвета (primary, accent), затем фоны (bg-light, bg-dark), затем текст (text-main, text-muted), затем шрифты и размеры (font-size-base, line-height-normal).
3. **Критичные метрики:** Ширина контейнера (чтобы контент не растягивался), размеры шрифтов (для иерархии) и отступы (margin, padding), так как они создают "воздух" в дизайне.
4. **Система сетки:** В макете используется 12-колоночная сетка (видно по линейкам). В CSS она переносится с помощью `display: grid; grid-template-columns: repeat(12, 1fr);`.
5. **Сложности с типографикой:** Figma использует пиксели (px), а веб — относительные единицы (rem, em). Также в Figma может быть нестандартный межбуквенный интервал (letter-spacing), который нужно переносить вручную.
6. **Адаптивность без мобильного макета:** Использовать подход Mobile First. Прописать базовые стили для маленьких экранов (в одну колонку) и через `@media (min-width: 768px)` добавлять стили для десктопа.
7. **Инструменты браузера:** Вкладка "Elements" (просмотр CSS), "Device Toolbar" (F12 -> иконка телефона) для проверки адаптивности и наложения макета.
8. **Экспорт изображений:** В Figma выделить картинку -> в панели Design внизу блок "Export" -> выбрать формат (SVG для иконок, WebP/PNG для фото) и нажать "Export".
9. **Отсутствие шрифта:** Использовать Google Fonts (если шрифт там есть) или найти похожий аналог (например, Inter заменяется на Arial или Roboto). Можно конвертировать шрифт в веб-формат (woff2) и подключать локально.
10. **Методологии:** БЭМ (для классов), использование CSS-переменных (как в этом проекте) и дизайн-системы (Figma-компоненты), чтобы изменения в макете легко переносились в код.
