## Описание проделанной работы
При верстке использовались семантические теги (`<header>`, `<section>`, `<footer>`). 
Цвета и шрифты вынесены в CSS-переменные (`variables.css`) для удобства поддержки.
Сетка реализована с помощью CSS Grid (секция преимуществ) и Flexbox (шапка и футер).
Добавлена адаптивность для планшетов и мобильных устройств с помощью медиа-запросов.
