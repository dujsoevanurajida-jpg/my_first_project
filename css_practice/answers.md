1. **Разница между классом и ID:** ID имеет более высокую специфичность (100), чем класс (10). ID можно использовать только один раз на странице, а классы можно применять многократно.
2. **Как работает каскад:** При конфликте правил браузер смотрит на специфичность селекторов. Если она одинаковая — применяется то правило, которое написано в коде ниже. Если указан `!important`, оно перебивает всё.
3. **Специфичность селекторов:**
   - `ul li.important` — 0, 1, 2 (один класс, два тега)
   - `#site-title` — 1, 0, 0 (один ID)
   - `.content > .featured-post` — 0, 2, 0 (два класса)
4. **Наследование:** 
   - Наследуются: `color`, `font-family`, `font-size`.
   - Не наследуются: `margin`, `padding`, `border`.
5. **Разница между `>` и пробелом:** `>` выбирает только прямых дочерних элементов. Пробел (селектор потомков) выбирает элементы на любой глубине вложенности.
6. **Псевдоклассы `:hover` и `:nth-child()`:** `:hover` нужен для эффектов при наведении мыши (например, подсветка кнопки). `:nth-child()` нужен для выбора элементов по порядку (например, чтобы покрасить каждую четную строку таблицы в другой цвет).
7. **`!important`:** Заставляет правило игнорировать специфичность и применяться всегда. Использовать с осторожностью, так как это ломает каскад, и потом очень сложно переопределить стиль.
8. **Псевдоэлементы `::before` и `::after`:** Позволяют добавить контент до или после элемента без изменения HTML. Могут содержать текст, иконки, декоративные элементы. В CSS обязательно нужно писать свойство `content`.
9. **Порядок при равной специфичности:** Побеждает то правило, которое стоит **ниже** в файле стилей.
10. **Инструменты разработчика:** Позволяют в реальном времени видеть, какие стили применены к элементу, какая специфичность победила, и можно тут же менять значения, чтобы протестировать вид.
