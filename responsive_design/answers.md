1. **Viewport meta tag:** Это тег `<meta name="viewport" content="width=device-width, initial-scale=1.0">`. Он важен, потому что сообщает браузеру мобильного устройства, что ширина страницы должна быть равна ширине экрана, а не масштабироваться под десктоп.
2. **Подходы:** Я использовала Responsive (отзывчивый) дизайн, так как в работе применяются медиа-запросы для плавного изменения макета под разные экраны. Также элементы Fluid (резиновые), так как ширина контейнера задана в процентах.
3. **Mobile First:** Это подход, при котором сначала пишутся стили для мобильных устройств, а затем через `min-width` добавляются стили для планшетов и десктопов. Его преимущество — более легкий и быстрый код для мобильных, которые сейчас составляют большинство трафика.
4. **Единицы измерения:** Проценты (`%`), `rem` (относительно размера шрифта корневого элемента) и `vw/vh` (относительно ширины/высоты экрана). Они предпочтительны, потому что позволяют элементам масштабироваться пропорционально экрану.
5. **Функция clamp():** Позволяет задать минимальное, предпочтительное и максимальное значение шрифта (например, `clamp(1.5rem, 5vw, 2.5rem)`). Это избавляет от необходимости писать кучу медиа-запросов только для изменения размера текста.
6. **Брейкпоинты:** 1024px (планшеты), 768px (мобильные), 480px (маленькие экраны). Эти значения взяты из стандартных разрешений популярных устройств.
7. **Медиа-запросы:** `@media` позволяет применять стили только при определенных условиях. Синтаксис: `@media (max-width: 768px) { ... }`.
8. **max-width и min-width:** `max-width` используется в подходе Desktop First (применяется, когда экран *меньше* указанного значения). `min-width` используется в Mobile First (когда экран *больше* значения).
9. **Адаптивные изображения:** Используется CSS-свойство `max-width: 100%;` и `height: auto;`. Это заставляет картинку не вылезать за пределы родительского контейнера и сохранять пропорции.
10. **Инструменты браузера:** Вкладка "Elements" (просмотр CSS), режим "Device Toolbar" (F12 -> иконка телефона) для эмуляции разных разрешений, а также вкладка "Network" для проверки скорости загрузки.
